# Docs

Written record of decisions, so the reasoning outlives the conversation it came from.

| Folder | Holds |
| --- | --- |
| [`adr/`](./adr) | Architecture Decision Records — technical choices and their trade-offs |
| [`product/`](./product) | Product decisions — scope, users, behaviour |

## How to add one

1. Copy the folder's `TEMPLATE.md` to `NNNN-short-title.md`, incrementing the number.
2. Fill it in. Keep it short — a decision, not an essay.
3. Add a row to the folder's index table.

Records are immutable once accepted. To change a decision, write a new one and mark the old one `Superseded by NNNN`.
